# Scripts

This folder is reserved for operational automation and project maintenance tasks.

Planned contents include:

- model training entrypoints
- data preparation and preprocessing utilities
- deployment or bootstrap helpers
- validation and smoke tests
- database migration or repair scripts
- one-off maintenance commands

This directory is intentionally empty right now because the migration is still in progress and the project has not yet standardized its operational scripts.

When scripts are added, they should be reusable, documented, and kept outside the application runtime directories.
