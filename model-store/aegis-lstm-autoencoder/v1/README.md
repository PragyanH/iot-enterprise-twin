# Aegis LSTM model store

This is the versioned model artifact directory for the Aegis digital twin LSTM autoencoder.

It is intended to contain:

- model weights or checkpoints
- config files for the model architecture
- preprocessing metadata
- version metadata
- any inferencing artifacts required by the backend service

The directory name `aegis-lstm-autoencoder` reflects the model family used for anomaly detection and trust scoring.
