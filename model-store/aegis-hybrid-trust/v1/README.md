# Aegis Hybrid Temporal Trust Engine v1

This package contains the stable runtime manifest and per-device baselines.
Optional learned artifacts are generated by `scripts/train_hybrid_models.py`:

- `temporal_vae_pi.pt`
- `temporal_vae_mock.pt`
- `xgboost.json`
- updated `metrics.json`
- `canonicalization.json` (versioned raw-to-canonical severe-SYN policy)
- `intelligence.json` (classifier confidence, unknown-anomaly, and trust-composition policy)

Deterministic security rules are versioned separately at
`rules/aegis_rules.yaml`; the eight presentation scenarios are in
`rules/mitre_scenarios.yaml`. `manifest.json` records all policy versions used by runtime.

Until those files exist, the backend uses its calibrated deterministic fallback.
The API exposes the active classifier backend so a missing artifact is not presented
as a trained model.

The runtime exposes full four-class probabilities and labels the backend as either
`xgboost` or `calibrated-fallback`. The fallback is operational continuity, not a
claim that XGBoost executed. `metrics.json` is limited to controlled synthetic and
replay validation; missing confusion-matrix/per-class fields are returned as null.
